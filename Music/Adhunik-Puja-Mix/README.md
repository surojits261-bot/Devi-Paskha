# 🎶 Adhunik Puja Mix

This folder contains the modern Bengali / contemporary Puja music collection for Devi-Paskha.

## Uploading tracks
- Upload the MP3 files for the finalized Adhunik Puja Mix collection into this folder.
- Keep the original audio files intact.
- Prefer descriptive filenames using the song title and artist.
- MP3 format is recommended for reliable browser playback.

## Target collection
The current curated collection is the 27-track Adhunik Puja Mix selected for the app.
